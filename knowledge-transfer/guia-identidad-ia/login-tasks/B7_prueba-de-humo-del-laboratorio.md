# B7 — Prueba de humo del laboratorio

> **Batch:** B · **Tamaño:** S · **Depende de:** B4, B6

## 1. Contexto
Hay que verificar que el laboratorio funciona sin secretos en el repositorio.

## 2. Objetivo
Hacer una prueba de humo del laboratorio.

## 3. Qué hacer
1. Hacer login con el usuario de prueba.
2. Verificar que el token se valida en la API.
3. Verificar que `tid` coincide.
4. No guardar secretos en el repositorio.

## 4. Aceptación
- Login completo funciona.
- El token se valida en la API.

## 5. Fuera de alcance
- Prueba de SAML (tarea B9).
