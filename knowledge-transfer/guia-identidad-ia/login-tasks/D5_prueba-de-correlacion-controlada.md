# D5 — Prueba de correlación controlada

> **Batch:** D · **Tamaño:** S · **Depende de:** C8, D6

## 1. Contexto
Hay que probar que la correlación entre instituciones está controlada.

## 2. Objetivo
Diseñar una prueba de correlación controlada.

## 3. Leer primero
- `../01-explicacion-logins-y-ia.md`, sección 6.3.

## 4. Qué hacer
1. Diseñar una prueba que verifique que el `global_identity_id` es el mismo para la misma persona en dos instituciones.
2. Verificar que el admin de una institución no ve las otras.
3. Documentar el resultado.

## 5. Aceptación
- Prueba diseñada y documentada.
