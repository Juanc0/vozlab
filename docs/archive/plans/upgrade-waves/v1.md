## Goal

Bring every runtime, library, connection, protocol, schema and database in
VozLab to a supported/current line, in the six waves already defined in
`docs/knowledge/dependency-lifecycle.md` §5, without changing any public
contract or domain behaviour. Done means: `pnpm turbo run build type-check
test` green, `pnpm lint` green with 0 errors, the integration suite green
against a fresh PG 18 + Valkey instance, the Playwright E2E suite green, the
Python gate green, image builds green, and `docs/knowledge/dependency-lifecycle.md`
re-verified with a new date stamp plus one ADR per major upgrade that touched
a security property or a public contract.
