## Goal

Done means: every list in `/admin` and `/workspace-admin` is rendered as an
accessible data table (`<table>` with `<thead>`/`<tbody>`, `scope="col"` headers,
sticky first column where useful) instead of `<ul>`/`<li>` rows, and every
"create new" form (create workspace, add member, create invitation, create join
code, create event code) opens in a `ModalDialog` triggered by a button placed
at the upper-right of the table's title row. Row actions stay inline on each
row. No inline creation forms remain on the list views. The proposals page is
the reference table pattern.
