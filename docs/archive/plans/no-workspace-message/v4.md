## Goal

Simplify the `no-membership` card to a single content block: the title above
and the button below, both centred horizontally. The redundant message text is
removed from the markup and from both locales. Done means: the card renders
only the heading and the `/join` button in a vertically stacked, horizontally
centred layout; `app.noWorkspaceText` is gone from `es.ts` and `en.ts`; the
chrome and outer spacing from v1/v2 are untouched; and the gate stays green.

Decisions taken during scoping (2026-10-31):

- i18n: remove the now-unused `app.noWorkspaceText` key from both locales.
- Chrome: keep the floating-bar chrome and outer spacing (v1/v2).
- Identity: v4 of `no-workspace-message`, continuing v1–v3.
