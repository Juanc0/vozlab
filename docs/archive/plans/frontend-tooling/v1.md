## Goal

Make the agent harness (MCPs, skills, commands, scripts, AGENTS.md, living
docs) ready to drive frontend work to industrial UI/UX standards: layout,
components, schemas and window sections of the views already shipped
(login, graph canvas, proposals, discussions, admin). Done means: an agent
opening a frontend plan can (1) inspect a running page via Playwright + Chrome
DevTools, (2) capture screenshots + HTML at desktop/mobile baselines,
(3) diff before/after, (4) consult the documented skill/MCP inventory, and
(5) follow a written example to open a small scoped frontend plan. No UI
code changes ship in this plan.

## Out of scope (this version)

- Actual UI redesign of any shipped view (login, canvas, proposals, discussions,
  admin) → future `plans/frontend-ux/v1` (or per-flow plans opened using the
  T6 walkthrough).
- New component library or design-system migration → future plan.
- Mobile-native or iOS work → `ios-design` skill only if requested.
- Figma integration → requires Figma files we do not have; revisit in v2.
