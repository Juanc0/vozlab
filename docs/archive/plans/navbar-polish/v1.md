> Slice: horizontal (i18n → sidebar component → docs → captures).
> Context: [docs/components/web-pwa.md](../../components/web-pwa.md) §The layout,

> (predecessor: join action moved into the navbar).
> Opened: 2026-11-01 from a follow-up UI request: the "join with an event
> code" label overflows its button, and the language selector is too narrow
> and should use the full navbar width.

## Goal

Polish two controls in the navigation column. Done means: the join button uses
a shorter, purpose-focused label ("Unirse a un evento" / "Join an event")
that fits on one line and can wrap if needed; the language selector becomes a
full-width control with the same margins as the other navbar controls; and the
gate stays green. The join button's route (`/join`) and the auth pages'
"join with an event code" wording are untouched.

Decisions taken during scoping (2026-11-01):

- Join label: purpose-focused, no "code" word → new key `common.joinEvent`.
- Locale selector: full-width select with the existing label above it.
- Identity: new area `navbar-polish`.
