## Goal

Make the navigation column reflect what the signed-in user can actually do.
Done means: workspace-scoped links (graph, proposals, discussions) are removed
from the DOM unless the user has at least one workspace membership; the admin
link is removed from the DOM unless `systemRole === 'ADMIN'`; `request-access`
stays always visible; the collapsed rail's workspace control shows a 2×2 grid
icon (decorative) while keeping the active workspace name as its accessible
name; and the gate stays green.

Decisions taken during scoping (2026-11-01):

- Gating is structural (`{#if}`), not CSS, so inaccessible links do not exist
  in the DOM (security/clarity).
- `request-access` is always visible (discovery tool).
- Rail workspace icon: grid/squares, with sr-only workspace name preserved.
