## Goal

Restore the join button's height to the standard control height so it matches
the logout button. Done means: the expanded join button uses `btn btn-secondary
w-full` (fixed `--control-height`, `white-space: nowrap`) like the logout
button, relying on the shorter `common.joinEvent` label to fit on one line; and
the gate stays green.

Decisions taken during scoping (2026-11-01):

- Height: standard control height (no `h-auto`), matching the logout button.
- The shorter purpose-focused label (v1) is what makes it fit on one line.
