## Goal

The identity storage carries ONE coherent vocabulary (`global_users` and its
family — no half-renamed tables, columns, indexes, ports or fixtures left),
the two databases migrate from a single baseline fold each, the dev-cluster
orphans (`vozlab` DB, `vozlab_graph` AGE schema, executed backfill scripts)
are gone from the definitions, and the local dev volume is restarted so
`test:integration` finally runs green on the host exactly as it does in CI.
Done means: CI green on the last push with the new baseline + a fully green
local `pnpm --filter @vozlab/api test:integration` against the reset volume.

## Checkpoint protocol

Commit per task; each commit leaves `pnpm turbo run build type-check test`
(9/9) + `bash scripts/docs-hygiene.sh` green; after T1 and T2 push and watch
CI (the `integration` job provisions fresh DBs from the new baseline — it is
the authority that the collapse + rename are consistent). Never land T4's
`down -v` before the `pg_dump` backups exist and are listed in the commit
message.
