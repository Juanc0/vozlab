> Slice: horizontal (sidebar → layout → tests → docs → captures).

## Goal

Relocate the `/join` action to the navigation column and add bottom air to the
navbar. Done means: the no-membership card holds only its title; the sidebar
carries a "join with an event code" control next to (below) the workspace
selector in expanded mode and as an icon in the rail; the control is always
visible; the logout button no longer touches the floor of the navbar (a
`pb-4` on both the expanded and rail bottom groups); and the gate stays green.

Decisions taken during scoping (2026-10-31):

- Join button placement: below the workspace selector.
- Join button visibility: always visible (not only in no-membership).
- Logout bottom margin: `pb-4` (1rem) on the bottom groups.
- Identity: new area `navbar-join` (separate from `no-workspace-message`).
