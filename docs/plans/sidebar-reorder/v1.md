# Sidebar reorder — v1

> Slice: horizontal (component → tests → docs → captures).
> Context: [docs/components/web-pwa.md](../components/web-pwa.md) §The layout,
> [apps/web/src/lib/components/AppSidebar.svelte](../../apps/web/src/lib/components/AppSidebar.svelte).
> Opened: 2026-10-31 from a UI reorder request: the language selector, the
> workspace selector, the tenant (institution) switcher and the sign-out must
> sit at the **bottom** of the sidebar, in an order that reads top-to-bottom
> as scope → institution → preference → exit.

## Goal

Reorder the bottom of `AppSidebar` so the four account/scope controls group
together at the foot of the column — expanded and rail alike — in the order
**Workspace → Tenant → Language → Logout** (the tenant switcher only renders
when there is more than one linked ACTIVE tenant). Done means: the expanded
column renders the controls in that order, the rail projects the same order
(workspace, language, session/logout — tenant lives inside the session menu),
the unit tests lock the order, the component doc describes it, and the
before/after captures show only the intended change. No behaviour, styling or
accessibility regression.

Decisions taken during scoping (2026-10-31):

- Order: Workspace → Tenant → Language → Logout (scope, then institution,
  then global preference, then exit).
- Rail and mobile drawer follow the same order; the rail keeps its three
  existing icon controls (workspace, locale, session) reordered, because the
  tenant switcher is folded into the session menu there.
- Evidence scope: component doc + tests + before/after captures (not
  presentational only).

## Out of scope (this version)

- Changing `TenantSwitcher` visibility/switching logic → unchanged.
- Relocating the language selector to the shell chrome (the `LocaleSelector`
  comment mentions it) → `plans/frontend-ux/` or a later sidebar plan; the
  user asked for it in the sidebar.
- Mobile drawer diverging from the rail order → parity chosen in scoping.
- Dark mode / token changes → `plans/design-system/`.
- Adding new controls to the bottom group (e.g. settings link) → a later plan.
