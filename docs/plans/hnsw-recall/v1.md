## Goal

The Relator's neighbour query (`GET /api/v1/nodes/:id/neighbors`) returns the true top-5 nearest neighbours per workspace on a multi-workspace, skewed dataset, with recall ≥ 0.95 against an exact (non-index) answer, without changing the schema, the embedding model or the dimension. Done means: the integration test passes on a seeded multi-workspace dataset, the query runs inside a transaction with `SET LOCAL hnsw.iterative_scan`, and `pgvector ≥ 0.8.0` is confirmed in the image and documented.
