## Goal

Restructure the `no-membership` card so its content reads as three parts on one
row — **title on the left, message in the centre, button on the right** — using
the same grid as the graph view's floating toolbar, and stacking as
**title → message → button** on small screens. Done means: the three parts use
the toolbar's `grid-cols-[auto_minmax(0,1fr)_auto]` with `gap-x-6 gap-y-2` and
`px-7 py-3`; below `sm` they stack in reading order; the wording, chrome and
outer spacing (v2) are untouched; and the gate stays green.

Decisions taken during scoping (2026-10-31):

- Grid: reuse the toolbar's exact grid and gaps.
- Stacking: title, then message, then button (top to bottom) below `sm`.
- Identity: v3 of `no-workspace-message`, continuing v1/v2.
