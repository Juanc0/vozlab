## Goal

Give the `no-membership` card the same outer air as the graph view's floating
toolbar. Done means: on small screens the card keeps `top-4 right-4 left-4`,
on large screens `top-7 right-7 left-0` (aligned to the content edge, since
the sidebar already supplies the gap), its internal padding stays `px-7 py-3`,
the page container no longer double-pads this branch, and the gate stays green.
The wording, chrome and `/join` link are untouched.

Decisions taken during scoping (2026-10-31):

- Spacing: match the floating bar's placement (`top-4 right-4` / `top-7 right-7`,
  `left-4` / `left-0`), not a generic container bump.
- Identity: v2 of `no-workspace-message`, continuing the closed v1 (spacing
  sliver copied forward with origin cited).
